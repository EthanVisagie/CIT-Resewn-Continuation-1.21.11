# CIT Resewn Continuation 1.2.2-fork.14+26.3

Compatibility release for Minecraft 26.3 on Fabric.

## Fixed

- Ported the Fabric build from Minecraft 26.2 to 26.3.
- Updated the Fabric Loader, Fabric API, Mod Menu, Cloth Config, Loom, and Gradle targets for 26.3.
- Updated enchantment item rendering for the 26.3 `ItemQuads` submit API.

## Install

Install only the main jar:

- `citresewn-continuation-1.2.2-fork.14+26.3.jar`

The defaults module is bundled inside the main jar.
